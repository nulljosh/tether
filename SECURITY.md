# Security

## Reporting

Found something? Email **trommatic@icloud.com**. Don't open a public issue for anything exploitable.

You'll hear back within a week. This is a solo side project. No bounty, no SLA, just a reply.

## Supported versions

The tip of `main`. Nothing else.

## What keeps you safe

Tether has no account, no network code and no data store. It asks macOS for Bluetooth, reads the list of devices you already paired, and connects the ones named like a mouse. It never pairs, forgets or renames a device. Nothing is written to disk and nothing leaves your Mac.

The landing page is static files. No cookies, no analytics, no forms.
