Tether for Mac

Your mouse, back in a second.

When a Bluetooth mouse drops, the keyboard is all you have. Open Tether from Spotlight. It does the rest.

Get Tether See how it works

Free. Mac only. No account.

How it works

Two keys. That's it.

Press Command Space, type Tether, press Return. It starts connecting the moment it opens. When the mouse is back, press Return again and it's gone.

Drop the mouse

The real screen. Drop it and watch it come back.

Features

Built for the moment nothing else works.

Keyboard only

No pointer needed

Every button has a key. Return closes it. Escape too.

Fast

It never freezes

Re-pairing leaves old copies of your mouse behind. Tether calls every one at once, so a dead one can't hold up the live one.

Patient

It keeps trying

Leave it open and it watches. If the mouse drops again, Tether picks it right back up.

Private

Nothing leaves

No account. No network. Tether only talks to the mouse you already paired.

Get it

One file. One build.

Tether is open source. Clone it and run the build script. It needs macOS 26 and Xcode.
